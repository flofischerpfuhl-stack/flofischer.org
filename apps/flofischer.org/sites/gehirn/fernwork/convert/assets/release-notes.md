# Release notes 4.2

Fernwork 4.2 makes converting **faster** and simpler.

## What's new

- Six focused converters: Images, Video, Audio, Data, Tables, Documents
- Per-file progress and inline errors
- One broken file never stops the batch

## Numbers

| Format | Before | After |
| --- | --- | --- |
| HEIC to JPG | 2.4 s | 0.6 s |
| MOV to MP4 | 31 s | 9 s |
