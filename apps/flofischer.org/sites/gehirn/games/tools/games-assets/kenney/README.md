# Kenney models (CC0)

Unmodified GLB files from two Kenney kits, used by the Fern Rangers meadow (`tools/js/games/fern-rangers-meadow.js`),
which converts them to vertex colours and recolours them at runtime.

- `nature/`: Nature Kit, https://kenney.nl/assets/nature-kit (downloaded 2026-10-26, archive SHA-256
  `fa7974a0d342bfe63c38664ba9f8ec1a4aab8ea25f099bdc56870e33588c4d9d`)
- `town/`: Fantasy Town Kit 2.0, https://kenney.nl/assets/fantasy-town-kit (downloaded 2026-10-26, archive SHA-256
  `1a7530c09f4d2fa2cdee259876f089334f8b1f27fa86a0c4f54ef86cdd8676ef`), with its shared `Textures/colormap.png`
