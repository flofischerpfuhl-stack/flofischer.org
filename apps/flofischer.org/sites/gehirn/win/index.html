Windows-PC für Claude einrichten

Alles geht mit der Maus. Du brauchst nur diese Seite, das Terminal und einen Klick auf „Kopieren“.

  1. Rechtsklick auf das Start-Symbol → Terminal (Administrator) → „Ja“.
  2. Hier auf Kopieren klicken:
    irm https://gehirn.flofischer.org/win/setup.txt | iex
  3. Im Terminal einmal Rechtsklick – das fügt den Befehl ein. Dann Enter drücken (Bildschirmtastatur: Symbol unten rechts in der Taskleiste oder Win-Einstellungen → Barrierefreiheit → Tastatur).
  4. Warten, bis grün „Fertig“ dasteht (ein paar Minuten).
  5. Unten rechts im Tray (ggf. Pfeil ^) das Tailscale-Symbol anklicken → Log in → mit flofischer.pfuhl@ anmelden.
  6. Claude Bescheid sagen – den Rest macht er per SSH.
